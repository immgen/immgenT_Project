# immgenT-CD4

This directory contains the code used to reproduce analyses and figures for the ImmGenT CD4 T cell atlas.

The analysis is organized as a [workflowr](https://workflowr.github.io/) project. The main analysis notebook is:

`analysis/CD4_workflow.Rmd`

A rendered version of the workflow is available in:

`docs/CD4_workflow.html`

## Data

Data required to reproduce the analyses are available through the immgenT Zenodo record:

https://zenodo.org/records/21839963

Download the CD4 data archive from Zenodo and place the required files in the appropriate project directories before running the workflow.

Large single-cell objects and other data files are hosted on Zenodo rather than GitHub.

## Analysis

The workflow contains the analyses used to characterize CD4 T cell states across tissues and immunological conditions, including:

- visualization of the immgenT CD4 reference landscape
- CD4 T cell cluster composition across tissues and conditions
- transcriptional characterization of resting and activated CD4 T cell states
- analysis of polarized CD4 T cell programs
- module-score comparisons of Th1-, Th2-, Th17-, and Tfh/Tchron-like programs
- antigen-specific CD4 T cell analyses
- TCR clonotype expansion analyses
- tissue-specific analyses
- analysis of effector and memory CD4 T cell states
- reference-based integration and mapping of external CD4 T cell datasets
- CITE-seq protein-expression analyses

## Repository structure

```text
immgenT-CD4/
├── analysis/
│   └── CD4_workflow.Rmd
├── code/
├── data/
├── docs/
├── output/
└── README.md
```

`analysis/` contains the workflowr analysis notebook.

`code/` contains supporting R scripts and functions used by the analysis.

`data/` contains small input files required by the workflow. Large datasets are distributed through Zenodo.

`docs/` contains the rendered workflowr website and figures.

`output/` is used for analysis outputs generated by the workflow.

## Running the analysis

Open the workflowr project in R and install the packages used by the analysis.

The complete workflow can be built with:

```r
library(workflowr)

wflow_build("analysis/CD4_workflow.Rmd")
```

Individual code chunks in `analysis/CD4_workflow.Rmd` can also be run independently for specific analyses and figures.

## ImmGenT

This analysis is part of the ImmGenT project, a reference atlas of T cell states across tissues and immunological conditions.
